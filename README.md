## ✨ امکانات

### 🔐 احراز هویت گوگل (OAuth 2.0)
- ورود امن با حساب گوگل با دامنه‌های دسترسی سرچ کنسول
- ذخیره و مدیریت خودکار توکن‌ها؛ **تازه‌سازی خودکار بدون نیاز به ورود مجدد**
- نمایش نام، ایمیل و آواتار کاربر در هدر + خروج کامل با پاک‌شدن توکن‌ها
- **حالت نمایشی (دمو)**: بدون کلید گوگل، با داده نمونه فارسی برای تست کامل

### 🌐 مدیریت سایت‌ها (Properties)
- کارت‌های زیبا با فاویکون، آدرس، نوع (Domain / URL Prefix) و وضعیت تأیید مالکیت
- جستجو و فیلتر بین سایت‌ها + ورود یک‌ کلیکی به داشبورد هر سایت

### 📊 داشبورد ۱۰ بخشی (به زبان ساده!)
| بخش | توضیح |
|---|---|
| 📈 عملکرد جستجو | کلیک، نمایش، نرخ کلیک، جایگاه + نمودار تعاملی + ۶ جدول تفکیکی |
| 🔗 بازرسی URL | پرونده کامل هر صفحه: ایندکس، خزش، موبایل، نتایج غنی، کد HTTP |
| 📄 ایندکس‌گذاری | صفحات ثبت‌شده/نشده با ۹ دسته دلیل + راهنمای رفع هر کدام |
| 📱 موبایل | مشکلات متن کوچک، عناصر نزدیک، محتوای عریض، viewport |
| 🗺️ نقشه سایت | لیست + ارسال + حذف Sitemap |
| 🔒 امنیت | پنالتی‌ها و مشکلات امنیتی با راهنمای رفع و درخواست بازبینی |
| 🏗️ نتایج غنی | FAQ، مقاله، محصول، مسیر راهنما، نظر، ویدیو و... |
| 🔗 لینک‌ها | خارجی (سایت‌ها، صفحات، متن انکر) + داخلی |
| 🌡️ Core Web Vitals | LCP، INP، CLS با تفکیک موبایل/دسکتاپ |
| 🗑️ حذف موقت | ثبت و لغو درخواست‌های Removal |

### 🎨 رابط کاربری
- کاملاً **فارسی و راست‌چین (RTL)** با فونت **وزیرمتن**
- حالت **روشن/تاریک**، طراحی ریسپانسیو موبایل/دسکتاپ
- انیمیشن‌های نرم، Skeleton Loading، نمودارهای تعاملی Recharts

### 💡 راهنمای درون‌برنامه‌ای
- آیکون ❓ کنار **هر** بخش و معیار با توضیح ساده و مثال روزمره
- دیالوگ «راهنمای داشبورد» جامع ۱۱ بخشی برای مبتدی‌ها

### ⚙️ قابلیت‌های اضافی
- مقایسه بازه زمانی با **درصد تغییرات** روی همه معیارها
- خروجی **CSV** (سازگار با اکسل) از همه جدول‌ها + خروجی **PDF** گزارش
- **نوتیفیکیشن هوشمند**: تحلیل خودکار داده و هشدار افت/رشد
- **خلاصه وضعیت کلی**: امتیاز سلامت سایت از ۱۰۰
- **کش‌گذاری** داده‌ها برای کاهش فراخوانی API گوگل

## 🖥️ نصب روی هاست اشتراکی cPanel — بدون ترمینال، بدون Node.js!

نسخه **استاتیک cPanel** این برنامه به‌صورت یک فایل ZIP آماده منتشر می‌شود که کل آن در **مرورگر** اجرا می‌شود:

- ✅ **بدون ترمینال**، بدون SSH، بدون نصب هیچ پکیجی
- ✅ **بدون Node.js** روی هاست — حتی روی ارزان‌ترین هاست اشتراکی
- ✅ **بدون دیتابیس** — هیچ MySQL/SQLite‌ای لازم نیست
- ✅ نصب در ۳ قدم: **آپلود ZIP → Extract → باز کردن دامنه**

```text
۱) فایل ZIP را از صفحه Releases دانلود کنید
۲) در cPanel → File Manager → public_html آپلود و Extract کنید
۳) دامنه خود را باز کنید — داشبورد آماده است! 🎉
```

📥 دانلود بسته: [**Releases → Persian-Search-Console-cPanel-v1.1.0.zip**](releases)

📖 **راهنمای گرافیکی کامل قدم‌به‌قدم با تصویر:** [`docs/install-guide-cpanel.html`](docs/install-guide-cpanel.html) — شامل ۳۳ اسکرین‌شات (همه بخش‌های برنامه + محیط cPanel + Google Cloud)، عیب‌یابی خطاهای رایج و پرسش‌های متداول. نسخه خودکفای آن (تک‌فایل، بدون نیاز به اینترنت) داخل خود بسته ZIP هم قرار دارد.

در حالت نمایشی، همه امکانات با داده نمونه فارسی کار می‌کنند؛ برای داده واقعی، Client ID گوگل را از داخل خود برنامه (بدون دخالت هاست) تنظیم می‌کنید — آموزش مصور در بخش ۹ راهنما.

> 💡 برای توسعه محلی یا اجرای سرور کامل (Next.js + Prisma)، از راه‌اندازی سریع پایین استفاده کنید. هاست اشتراکی دارید؟ فقط بخش cPanel کافی است.

## 🚀 راه‌اندازی سریع (۳ دقیقه!)

### ۱. نصب وابستگی‌ها

```bash
# با bun (پیشنهادی)
bun install

# یا با npm
npm install
```

### ۲. تنظیمات محیط

```bash
cp .env.example .env
```

فایل `.env` را باز کنید. اگر فعلاً کلید گوگل ندارید، همان پیش‌فرض‌ها کافی است
و برنامه در **حالت نمایشی** کامل کار می‌کند:

```env
DATABASE_URL="file:./db/custom.db"
GOOGLE_CLIENT_ID=""
GOOGLE_CLIENT_SECRET=""
```

### ۳. آماده‌سازی دیتابیس

```bash
bun run db:push
```

### ۴. اجرا

```bash
bun run dev
```

برنامه روی `http://localhost:3000` اجرا می‌شود.
روی **«ورود به حالت نمایشی»** کلیک کنید تا داشبورد کامل با داده نمونه فارسی را ببینید!

## 🔑 راه‌اندازی اتصال واقعی به گوگل (گام‌به‌گام)

برای دیدن **داده‌های واقعی سایت خودتان**، مراحل زیر را در Google Cloud Console انجام دهید:

### مرحله ۱: ساخت پروژه در گوگل

1. به [console.cloud.google.com](https://console.cloud.google.com) بروید و وارد شوید
2. از بالای صفحه روی منوی پروژه کلیک کنید → **New Project**
3. نامی مثل `Persian Search Console` بگذارید و **Create** بزنید
4. پس از ساخت، مطمئن شوید همین پروژه **انتخاب شده** است

### مرحله ۲: فعال‌سازی Search Console API

1. در منوی کنار، به **APIs & Services → Library** بروید
2. عبارت `Google Search Console API` را جستجو کنید
3. روی آن کلیک و دکمه **Enable** را بزنید

### مرحله ۳: ساخت صفحه رضایت (OAuth Consent)

1. به **APIs & Services → OAuth consent screen** بروید
2. **Get started** را بزنید و اطلاعات را پر کنید:
   - **App name**: `Persian Search Console`
   - **User support email**: ایمیل خودتان
   - **Audience**: برای استفاده شخصی، `External` و سپس فقط خودتان را Test user کنید
3. در بخش **Scopes** دامنه‌های زیر را اضافه کنید:
   ```
   https://www.googleapis.com/auth/webmasters.readonly
   https://www.googleapis.com/auth/webmasters
   ```
4. در بخش **Test users** ایمیل گوگل خودتان را اضافه کنید

### مرحله ۴: ساخت کلیدهای OAuth

1. به **APIs & Services → Credentials** بروید
2. **Create Credentials → OAuth client ID** را بزنید
3. نوع **Web application** را انتخاب کنید
4. در بخش **Authorized redirect URIs** آدرس زیر را اضافه کنید:
   ```
   http://localhost:3000/api/auth/google/callback
   ```
   (اگر روی دامنه واقعی اجرا می‌کنید، آدرس دامنه‌تان را هم اضافه کنید)
5. **Create** بزنید و **Client ID** و **Client Secret** را کپی کنید

### مرحله ۵: تنظیم برنامه

کلیدها را در فایل `.env` قرار دهید:

```env
GOOGLE_CLIENT_ID="کلید-شما-اینجا.apps.googleusercontent.com"
GOOGLE_CLIENT_SECRET="GOCSPX-کلید-مخفی-شما"
GOOGLE_REDIRECT_URI="http://localhost:3000/api/auth/google/callback"
NEXT_PUBLIC_APP_URL="http://localhost:3000"
```

برنامه را ری‌استارت کنید و با دکمه **«ورود با حساب گوگل»** وارد شوید! 🎉

> 💡 نکته: توکن‌ها به‌صورت امن در دیتابیس ذخیره می‌شوند و در صورت انقضا،
> خودکار با Refresh Token تازه می‌شوند — نیازی به ورود مجدد نیست.

## ⚠️ نکته مهم درباره داده‌ها (شفافیت کامل)

این پروژه دو حالت داده دارد:

| بخش | حالت واقعی (OAuth) | حالت نمایشی (دمو) |
|---|---|---|
| عملکرد جستجو | ✅ API واقعی گوگل | ✅ داده نمونه قطعی |
| لیست سایت‌ها | ✅ API واقعی گوگل | ✅ داده نمونه |
| نقشه‌های سایت | ✅ API واقعی گوگل | ✅ تعاملی |
| بازرسی URL | ✅ API واقعی گوگل | ✅ داده نمونه |
| ایندکس، موبایل، امنیت، نتایج غنی، لینک‌ها، CWV، حذف | ⚠️ داده نمایشی/برآوردی* | ✅ داده نمونه |

> *) **توضیح**: گوگل API عمومی برای این گزارش‌ها ارائه نمی‌دهد (فقط از رابط وب سرچ کنسول قابل مشاهده‌اند). این بخش‌ها با داده‌های نمایشی واقع‌گرایانه و برچسب «داده نمایشی» کار می‌کنند تا تجربه کامل داشبورد حفظ شود. جداول عملکرد، سایت‌ها، نقشه‌ها و بازرسی کاملاً به API واقعی وصل هستند.
